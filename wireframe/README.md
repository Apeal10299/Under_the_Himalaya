# Wireframe Documentation

This folder contains a simple wireframe mockup for the homepage/footer layout.

## Layout Overview

- Dark teal background
- Left column with logo, headline, and descriptive text
- Center column with navigation links
- Right column with contact/resource info
- Footer bar with copyright and quick scroll controls
