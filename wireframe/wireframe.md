# Footer Wireframe Documentation

## Purpose

This document describes the dark footer wireframe used as a visual reference for the website footer section.

## Layout Sections

### 1. Left panel
- StoryCycle logo
- Brand title: "StoryCycle"
- Headline: "Understanding the Himalayans"
- Intro paragraph describing the organization and mission

### 2. Center navigation
- Explore
  - StoryCycle Website
  - Stories
  - Map
  - About
- Resources
  - Contact information / address details

### 3. Right contact info
- Phone number
- Email
- Office location
- USA office address

### 4. Bottom bar
- Copyright text
- Quick action area with upward scroll indicator

## Suggested Visual Treatment

- Background: `#0d3047`
- Text: `#ffffff`
- Secondary text: `#dfeaf2`
- Accent: `#8edaf7`
- Border: subtle low-opacity white line
- Type scale: large heading + clean sans-serif spacing

## Wireframe Notes

- The layout is intentionally minimal and high-contrast for readability.
- The composition balances storytelling text on the left with utility links and contact details on the right.
- This is meant to act as a design reference before implementation in full HTML/CSS.
